# 単元ごとの問題数

合計 **13,127 問**（単元 171 個）。すべての単元が20問以上。

難しさは、全員の1発正解率から連続値で測ります（初級・中級・上級のような区分は使いません）。

各教科の「ノンジャンル」には、指導要領の外の「発展内容」と、「入試の難問」を分けて置いています。ほかに、承認された「みんなの問題」を、ルールの出題範囲として選べます。
