# Premium の課金（月300円・年2,400円）の準備

料金：**月300円／年2,400円**（買い切りと家族プランはなし）。
学習の中身（全教科・全単元・全問題）は無料のまま。Premium は「別の問題」「問題の投稿」「過去の記録」「保護者用パスコード」「見た目の特典」。

## あなたにお願いする作業（App Store Connect）

1. **有料アプリの契約**：App Store Connect →「契約／税金／銀行口座」で「有料App」の契約に同意する。
2. **銀行口座と税の情報**を登録する（個人の場合も必要）。審査が入るので、早めに。
3. **小規模事業者向けプログラム**（手数料15％）に申し込む（対象になるか確認）。
4. **サブスクリプショングループ**を作る（例：「Premium」）。その中に2つの商品を登録する。

   | 種類 | 商品ID | 期間 | 価格 |
   |---|---|---|---|
   | 月額 | `com.ontamaudon.qlock.premium.monthly` | 1か月 | 300円 |
   | 年額 | `com.ontamaudon.qlock.premium.yearly` | 1年 | 2,400円 |

   - 日本円の価格帯に 300円・2,400円があるか、画面で確認してください（なければ近い価格を選ぶ）。
   - 無料体験（初回7日間など）をつけるかは、あなたが決める。
   - 各商品に「表示名」と「説明」を日本語で入れる。
5. **プライバシーポリシーと利用規約の URL** を用意する（ひな形は `docs/PRIVACY.md`・`docs/TERMS.md`）。
   GitHub Pages などで公開した URL を、App Store Connect の「Appのプライバシー」とアプリ情報に入れる。
6. 「Appのプライバシー」（栄養成分表示のような質問）に答える。収集するデータは `docs/PRIVACY.md` の表を参照。

## こちら（私）がやること

- `mathscreen/Services/Purchases.swift`（作成済み・まだ画面につないでいない）：商品の取得、購入、復元、状態の確認。
- 商品が登録できたら：設定の「仮登録」を本物の購入に置き換える。「購入を復元」ボタンと、料金・自動更新・解約方法の説明、利用規約・プライバシーポリシーへのリンクを置く。
- 購入後の状態を `SharedStore.isPremium` に反映する（今の画面はこれを見ているので、画面の変更は最小限）。
- TestFlight では、サンドボックスの購入で動作を確かめられる（実機でのテストは、あなたにお願いします）。

## App Store の審査で必要なこと

- アプリ内に「購入を復元」の入口があること。
- サブスクの料金・期間・自動更新・解約方法が、購入前の画面にわかりやすく書かれていること。
- 利用規約とプライバシーポリシーへのリンクが、アプリ内にあること。
- 課金で解除される機能が、説明どおりに動くこと。
