# 解くロックプランの課金（月300円・年2,400円）の準備

料金：**月300円／年2,400円**（買い切りと家族プランはなし）。
**方針（2026年11月に変更・審査ガイドライン 4.10 への対応）**：スクリーンタイムの機能（アプリロック）には課金しない。**無料トライアルは7日間**。
- 無料：アプリロック（ルール）、算数・数学の問題（問題集でも、ロックの問題でも）、記録タブ。
- 有料（トライアル中は使える）：英語・国語・社会・理科の問題、「問題を変える」、保護者用設定（パスコードで、ルールや設定を守る）。
- まだ決めていないこと：記録タブを無料にするか／契約が切れたときのブロックの扱い（おすすめ：いったんすべて解除して、契約の案内を出す）／お金に困っている人向けの無料の道（オファーコードなど）。
- 実装は、課金の実装のときに行う（いまのコードは、まだ「無料＋Premium（仮登録）」の形のまま）。

## あなたにお願いする作業（App Store Connect）— はじめての人向け

> 画面の名前は、Apple が変えることがあります。名前が少し違っていても、近い項目を探してください。
> 契約への同意など、いくつかの操作は「アカウントの持ち主（Account Holder）」にしかできません。ひとりで開発している場合は、あなたです。

入口は、パソコン（またはスマホのブラウザ）で https://appstoreconnect.apple.com を開いて、Apple Developer の Apple ID でログインすることです。

### ステップ1：お金を受け取る準備（いちばん時間がかかるので、最初に）

1. ホームの **「契約/税金/銀行口座」**（英語表示だと Business など）を開く。
2. **「有料App」**（Paid Apps）の契約を探して、**「規約を確認」→ 同意**する。
3. 同じ画面で、**銀行口座**を追加する（日本の口座。口座名義はアカウント名と同じにする）。
4. **税金の情報**を入力する。画面の質問に答える形で、米国の税のフォーム（日本の個人は W-8BEN）も出てきます。案内に沿って入力してください。わからない点は、Apple のサポートか税理士に聞くのが確実です。
5. 契約の状態が **「有効」** になれば完了。入力のあと、反映まで数日かかることがあります。
6. （おすすめ）**「App Store Small Business Program」**（小規模事業者向けプログラム）に申し込む。通れば、Apple に払う手数料が、30％から15％になります。

### ステップ2：サブスクリプションの商品をつくる

1. App Store Connect で、**「マイApp」→「解くロック」**を開く。
2. 左のメニューの **「収益化」→「サブスクリプション」** を開く（古い表示だと「App内課金」の中）。
3. **「サブスクリプショングループを作成」**。名前は「解くロックプラン」にする。
4. グループの中で、**「サブスクリプションを作成」** を押して、次の2つをつくる。

   | | 月額 | 年額 |
   |---|---|---|
   | 参照名（自分用の名前） | 解くロックプラン 月額 | 解くロックプラン 年額 |
   | 製品ID（あとで変えられない） | `com.ontamaudon.qlock.plan.monthly` | `com.ontamaudon.qlock.plan.yearly` |
   | 期間 | 1か月 | 1年 |
   | 価格 | 300円 | 2,400円 |

   - **製品ID** は、私のコードと**同じ文字**にしてください（1文字でも違うと買えません）。
   - 価格は、国の一覧から日本を選び、300円／2,400円を選ぶ。一覧にない場合は近い価格を選び、私に教えてください。
5. それぞれに、**日本語の「表示名」と「説明」** を入れる。例：表示名「解くロックプラン（月額）」、説明「アプリロックなど、すべての機能が使えます」。
6. グループにも、日本語の表示名を入れる（購入画面に出る名前）。

### ステップ3：7日間の無料トライアルを付ける

1. 各商品（月額・年額）の画面で、**「導入オファー」** の欄を開き、**「作成」** を押す。
2. 種類は **「無料」**、期間は **「7日間」**、対象の国は **「日本」**（ほかも選んでよい）にする。
3. 月額と年額の**両方**に付ける。
- 1人が受けられる無料トライアルは、同じグループの中で**1回だけ**です。月額で使ったあとに、年額で2回目の無料トライアルは受けられません。
- 参考：Apple の説明ページ「[導入オファーの設定](https://developer.apple.com/help/app-store-connect/manage-subscriptions/set-up-introductory-offers-for-auto-renewable-subscriptions)」。

### ステップ4：審査に出す準備

1. 各商品に、**審査用のスクリーンショット**（購入画面の画像）と**メモ**を入れる。購入画面ができたあとで、私が画面の見本を用意します。
2. 商品の状態が **「申請準備完了」**（Ready to Submit）になればよい。
3. **プライバシーポリシーと利用規約を、インターネットで公開**する。ひな形は `docs/PRIVACY.md` と `docs/TERMS.md`。GitHub Pages など無料の方法で公開できます。その URL を、アプリ情報の「プライバシーポリシーURL」に入れる。
4. 最初の審査のときは、アプリの新しいバージョンのページで、**「App内課金とサブスクリプション」** の欄に、この2つの商品を追加して、アプリと一緒に審査に出す。

### ステップ5：テスト用のアカウントを作る

1. App Store Connect の **「ユーザとアクセス」→「サンドボックス」→「テスター」** で、テスト用の Apple ID を作る（実在しないメールアドレスでも作れるが、受信できるアドレスが安全）。
2. iPhone の「設定」→「App Store」→ 一番下の **「サンドボックスアカウント」** で、そのアカウントでログインする。
3. TestFlight のアプリで購入を試すと、お金はかからず、課金の動きだけ確かめられます。

## こちら（私）がやること

- `mathscreen/Services/Purchases.swift`（作成済み・まだ画面につないでいない）：商品の取得、購入、復元、状態の確認。
- 商品が登録できたら：設定の「仮登録」を本物の購入に置き換える。「購入を復元」ボタンと、料金・自動更新・解約方法の説明、利用規約・プライバシーポリシーへのリンクを置く。
- 購入後の状態を `SharedStore.isPremium` に反映する（今の画面はこれを見ているので、画面の変更は最小限）。
- TestFlight では、サンドボックスの購入で動作を確かめられる（実機でのテストは、あなたにお願いします）。

## App Store の審査で必要なこと

- アプリ内に「購入を復元」の入口があること。
- サブスクの料金・期間・自動更新・解約方法が、購入前の画面にわかりやすく書かれていること。
- 利用規約とプライバシーポリシーへのリンクが、アプリ内にあること。
- 課金で解除される機能が、説明どおりに動くこと。
