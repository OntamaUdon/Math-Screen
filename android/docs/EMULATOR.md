# パソコン（Windows）のエミュレーターで、アプリを動かす

Android の端末がなくても、パソコンの中の「エミュレーター」（Android の端末をまねるソフト）で、アプリを動かせます。

## 1. Android Studio を入れる（最初の1回だけ）

1. https://developer.android.com/studio を開き、「Android Studio をダウンロード」から、Windows 用を入れる。
2. 起動すると、最初の設定の画面が出ます。「Standard」（標準）を選んで、そのまま進めます。必要なファイルのダウンロードに、しばらくかかります。
3. パソコンのメモリは、16GB くらいあると安心です。エミュレーターが重いときは、ほかのアプリを閉じてください。

## 2. エミュレーターを作る

1. Android Studio の最初の画面で「More Actions」→「Virtual Device Manager」。
2. 「＋」（Create Virtual Device）→「Pixel 7」など →「Next」。
3. システムの種類は、名前に **「Google Play」** と付いているもの（API 35 など）を選ぶ。課金を試すときに必要です。
4. 「Finish」。一覧の ▶ を押すと、エミュレーターが起動します。

## 3. アプリを入れる

1. ブラウザで GitHub の「Actions」→ 最新の「Android」を開く。
2. 下の「Artifacts」から `qlock-debug-apk` をダウンロードして、zip を開く（`app-debug.apk` が出てきます）。
3. `app-debug.apk` を、起動しているエミュレーターの画面に**ドラッグ＆ドロップ**する。数秒で入ります。
4. エミュレーターのアプリの一覧に「解くロック」が出ます。

※ これは開発用のビルドです。設定に「テスト用：無料で使う」が出るので、お金をかけずにプランの機能を試せます。

## 4. 確かめてほしいこと

1. はじめの案内を進める。「見守りの許可」で「同意して設定を開く」→ Android の設定の「ユーザー補助」→「解くロック（見守り）」をオンにする。
2. 設定 →「テスト用：無料で使う」を押す。
3. ホーム →「追加」→ 制限するアプリに「Chrome」などを選び、時間を「1分」にして保存。
4. Chrome を開いて、1分ほど待つ → Chrome の上に問題が出るか。
5. 問題に正解 →「解除してアプリに戻る」で Chrome に戻れるか。
6. もう一度ロックがかかったら、問題の右上の × → ホーム画面に戻り、Chrome を開くと、また問題が出るか。
7. エミュレーターに PIN を設定（エミュレーターの「設定」→「セキュリティ」→「画面ロック」）。ロック中に、エミュレーターの右の電源ボタンで画面を消して、またつける → ロック画面の上に問題が出るか。

気になったところは、画面の写真（エミュレーターの右のカメラのボタンで撮れます）を送ってください。

## 5. Google Play の申告に使う動画を撮る

ユーザー補助の申告には、「説明の画面 → 同意する流れ → 同意しない流れ」の動画が必要です。

1. エミュレーターの右の「…」（Extended controls）→「Record and Playback」→「Start Recording」。
2. 次の順に操作する。
   - アプリの設定 →「見守り（ユーザー補助）」の「オンにする」→ 説明の画面が出る
   - 「同意しない」を押す → 何も起きずに戻る
   - もう一度「オンにする」→「同意して設定を開く」→ Android の設定でオンにする
   - ルールを作り、時間がたつと、問題が出るところまで
3. 「Stop Recording」→ 保存（webm か gif）。YouTube に「限定公開」で上げて、その URL を申告に入れます。
