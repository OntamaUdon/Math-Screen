# mathscreen

**数学で、スマホの使いすぎを止める。**

指定したアプリを決めた時間だけ使うと、そのアプリにロックがかかります。中学〜大学入試レベルの数学の問題に正解すると、ロックが外れて使えるようになります。iOS アプリです（企画書のフェーズ1 = MVP）。

- UI：フラットデザイン（グレー基調 + ミント1色）
- 画面プレビュー（ブラウザで確認できるモック）：[`preview/index.html`](preview/index.html)
- Mac なしで TestFlight に配信する手順：[`docs/SETUP.md`](docs/SETUP.md)

## 使い方

1. 「見守るアプリ」の ＋ で、対象のアプリと時間（例：Instagram を 15 分）を設定
2. 合計 15 分使うと、そのアプリにブロック画面（シールド）が表示される
3. ブロック画面の **「問題を解く」** → 届いた **通知をタップ** → mathscreen で問題が開く
4. 正解すると解除。そこから次の 15 分でまたロックされる

> iOS の仕様上、ブロック画面には入力欄を置けず、アプリを直接開くこともできません。そのため Opal・ScreenZen と同じく、通知を経由して本体アプリを開きます。

## フェーズ1で実装した機能

| 企画書の項目 | 実装 |
|---|---|
| 対象アプリの選択 | `FamilyActivityPicker`（アプリ・カテゴリ・Web サイト） |
| アプリ利用時間の監視 | `DeviceActivity`。ルールごとに独立して監視 |
| 指定時間到達時の問題表示 | Monitor 拡張がシールドをかける → シールドのボタン → 通知 → 問題画面 |
| 正解・不正解判定 | 整数入力のテンキー。不正解なら何度でも再回答、3回間違えると「別の問題」 |
| 正解後の利用再開 | シールドを解除し、カウントをリセットして監視を再開 |
| 運営の問題データベース | 内蔵 60 問（4分野 × 3難易度 × 5問） |
| 緊急時の解除 | 問題画面と設定から。記録に「緊急解除」として残る |
| その他 | 練習モード、出題分野・難易度の設定、解除に必要な正解数（1〜3問）、記録（発動回数・正解数・正答率・連続正解など） |

### 問題データ

- `tools/build_problems.py` に全問題があり、**すべての正解を sympy で検算** してから `mathscreen/Resources/problems.json` を生成します。
- 答えはすべて整数です。√ や分数になる問題は「a√b/c と表したときの a + b + c」のように整数で答える形にしています。
- 問題を追加・修正したら `python3 tools/build_problems.py` を実行してください（CI でも検算されます）。

| 数学I・A | 5 | 5 | 5 |

## 構成

```
project.yml                     XcodeGen の設定（.xcodeproj は CI で生成）
mathscreen/                     アプリ本体（SwiftUI, iOS 17.4+）
  App/  Models/  Services/  Theme/  Views/  Resources/
Shared/                         本体と拡張で共有（App Group のデータ、シールド・監視の制御、通知）
MonitorExtension/               しきい値到達 → シールド + 通知
ShieldConfigurationExtension/   ブロック画面の見た目
ShieldActionExtension/          ブロック画面のボタン → 通知
tools/                          問題データ生成・検算、アイコン生成
preview/                        ブラウザで見られる UI モック
.github/workflows/              ビルド確認 / TestFlight アップロード
```

## 制限事項・今後

- 「連続使用時間」ではなく、監視開始（または前回の正解）からの **累積時間** で判定します（iOS の仕様）。
- iOS 17.4 以上が必要です（正解後にカウントを 0 から数え直す API が 17.4 から）。
- 「今日のスマホ利用時間」の表示は、別の拡張（DeviceActivityReport）が必要なため次の段階で対応します。
- フェーズ2以降（ユーザー登録・問題投稿・フィード・Supabase 連携など）は未実装です。
